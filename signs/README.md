# Printable signs

Generated by `node tools/make-signs.mjs`. Do not edit by hand — regenerate.

The generator needs Playwright: `npm i playwright` in the repository root.
Install it, do not symlink `node_modules` in from elsewhere. Cloudflare Pages
refuses to deploy a tree containing a link it cannot follow, and fails the
whole build with "build output directory contains links to files that can't
be accessed" — `node_modules` is gitignored, but only an actual directory is
matched by a pattern ending in a slash, so a symlink slips past it.

- `00-start-here.png` — the board for the gate. Points at the hunt itself.
- `01`–`10` — one per variety. The filename carries the slug and the code.

**Printing.** Matte laminate, not gloss. A glossy sign in low October sun
throws the camera's own reflection back at it and the code will not read.

Each sign ends in a dashed strip naming the variety it belongs beside. That
is for whoever places them — trim it off or fold it under once the sign is in
the ground, because the whole point of the hunt is that the pumpkin is not
named until it is scanned.

**Codes.** These are printed matter, so the codes in `assets/pumpkins.js` are
fixed the moment these go to print. Changing a `code` afterwards orphans a
sign standing in a field. Everything else about a variety can change freely.

Every sign in this folder has been decoded back from the rendered PNG to
confirm it resolves to the right URL.
